# odin-roshambo
The Odin Project's Rock, Paper, Scissors project as a part of their Foundations | JavaScript Basics curriculum

Create a game of rock, paper, scissors that a user can play against a computer within the dev console

Steps:

Create a function that will obtain computer's choice
    Choices include rock, paper, and scissors
    Choice must be random

Create a function to obtain a user's choice
    Valid choices include rock, paper, and scissors
    Return a valid choice based on user's input

Track computer and user scores
    Create variable for computer score
    Create variable for human score
    Make initial score 0

Create a function to play a single round
    Define parameters
        Create parameter for computer choice
        Create parameter for human choice
        Make human choice case insensitive
    Create ability for console to log a win or lose message
    Add a point to computer or human score based upon the round winner

Create function for entire game
    Ensure single round function is within entire game function
    Add function to recall choice functions
    Create loop to play game 5 times
